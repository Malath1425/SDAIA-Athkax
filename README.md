وصف المشكلة والهدف: وصف المشكلة: يسعى قطاع تطبيقات توصيل الطعام لتحسين معدل تحويل المستخدمين وزيادة اختيارهم للمنتجات المميزة بطريقة تدفعهم لإتمام الطلب. الهدف: قياس أثر إضافة ميزة بصرية جديدة تتمثل في شارة "الأكثر طلباً" (Most Popular Badge) على المنتجات، واتخاذ قرار إحصائي دقيق بشأن إطلاقها بشكل شامل. القرار المطلوب: اتخاذ قرار إطلاق الميزة (Rollout) أو إيقافها بناءً على أدلة إحصائية قوية. \_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_
